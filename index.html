📐 未來資料擴充架構規範 (Extensibility Architecture)

如何無縫擴充新的主題與簡報（例如 A2.2.2 超級個體）

本知識庫門戶遵循「資料與展示解耦」的現代化微架構設計。未來新增任何主題或筆記簡報，只需完成以下三個輕量步驟：

  1. 在 registry.js 註冊主題：於 KNOWLEDGE_REGISTRY.topics 新增一個配置物件，指定 id (如 A2.2.2)、主題標題、標籤與簡報連結 slides.html?topic=A2.2.2。
  2. 填寫標準資料來源 (JSON/JS)：參考 templates/module-template.json，填寫該主題的逐講資料（包含 num, title, beginner, advanced, image 等雙軌欄位）。
  3. 全自動串聯與發布：門戶與簡報播放器會自動辨識並載入新主題，透過 git push 直接在 GitHub Pages 上線！
